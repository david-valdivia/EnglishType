# Licenses for bundled artwork

Every illustration in `public/icons/` comes from Microsoft's Fluent Emoji set,
downloaded through the Iconify API by `scripts/fetch-icons.mjs`. The set is MIT
licensed, so the artwork ships with this app without per-icon attribution — the
notice below is all that is required.

Google's Noto Emoji (Apache 2.0) is the intended fallback for words Fluent Emoji
does not cover. Nothing in the current vocabulary needs it, so no Noto artwork is
bundled today; `scripts/fetch-icons.mjs` would need its set list extended before
adding a word that depends on it.
